# CONTRIBUTING

Спасибо за вклад!

## Принципы

- Делайте небольшие, понятные изменения.
- Для нетривиальной логики добавляйте тесты.
- Поддерживайте документацию актуальной.

## Как вносить изменения

1. Создайте ветку от `main`/`work`.
2. Внесите изменения в `src/` и при необходимости в `tests/`.
3. Прогоните локальные проверки (тесты, линтер).
4. Создайте PR с понятным описанием:
   - что сделано;
   - зачем сделано;
   - как проверяли.

## Checklist для PR

- [ ] Изменения атомарны и понятны.
- [ ] Нет лишних файлов и временного мусора.
- [ ] Документация обновлена (если нужно).
- [ ] Добавлены тесты или объяснено их отсутствие.
